光影盟 · 怎么打开前端（桌面请留着这份）

【你需要开着的环境】
1）本机 Node 课堂服务（端口 3000）
2）浏览器老师端页面

关掉「启动环境 / 开始上课」那个黑色终端窗口后，
前端就打不开了——这是正常的，再开一次即可。

【桌面按钮怎么用】
• 光影盟-启动环境（或 光影盟-开始上课 / GY-Start）
  → 打开课堂环境：同步代码 + 启动服务 + 打开浏览器
  → 上课期间请保持这个窗口开着

• 光影盟-打开老师端（或 GY-Teacher）
  → 只打开浏览器；若服务没开会自动帮你启动

• 光影盟-更新（或 GY-Update）
  → 拉最新代码；更新完仍需再点「启动环境」上课

• 光影盟-诊断
  → 检查目录、版本、Node 是否正常

【老师端地址（可收藏）】
http://127.0.0.1:3000/?mode=teacher

【本机唯一目录】
/Users/liwei/Photon

【需要预先安装的环境（装一次即可）】
• Node.js LTS：https://nodejs.org
• Git（Mac 一般已有；没有就执行：xcode-select --install）

【打不开时按这个顺序】
1. 双击「光影盟-启动环境」
2. 等终端出现服务日志，浏览器应自动弹出
3. 浏览器按 Cmd+Shift+R 强制刷新
4. 仍不行：双击「光影盟-诊断」看报错
