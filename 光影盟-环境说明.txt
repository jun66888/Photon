光影盟 · 怎么打开前端（桌面请留着这份）

【你需要开着的环境】
1）本机 Node 课堂服务（端口 3000）
2）公网扫码隧道（默认随启动一起开，学生可用手机流量）
3）浏览器老师端页面

关掉「启动环境 / 开始上课」那个黑色终端窗口后，
前端和扫码都会失效——再开一次即可。

【学生签到（手机流量）】
• 老师电脑必须能上网（用来建 Cloudflare 隧道）
• 双击「光影盟-启动环境」，等终端出现 https://….trycloudflare.com
• 签到页二维码会自动变成这个 https 地址
• 学生用微信扫一扫即可，不必连教室 Wi‑Fi
• 若二维码还是局域网地址：点签到页「刷新流量地址」

【桌面按钮怎么用】
• 光影盟-启动环境（或 光影盟-开始上课 / GY-Start）
  → 同步代码 + 启动服务 + 流量隧道 + 打开浏览器
  → 上课期间请保持这个窗口开着

• 光影盟-打开老师端（或 GY-Teacher）
  → 只打开浏览器；若服务没开会自动帮你启动

• 光影盟-更新（或 GY-Update）
  → 拉最新代码；更新完仍需再点「启动环境」上课

• 光影盟-诊断
  → 检查目录、版本、Node 是否正常

【老师端地址（可收藏）】
http://127.0.0.1:3000/?mode=teacher

【本机唯一目录】
/Users/liwei/Photon

【需要预先安装的环境（装一次即可）】
• Node.js LTS：https://nodejs.org
• Git（Mac 一般已有；没有就执行：xcode-select --install）
• 可选：brew install cloudflared（没有也会自动下载）

【打不开时按这个顺序】
1. 双击「光影盟-启动环境」
2. 等终端出现服务日志与流量扫码 https 地址
3. 浏览器按 Cmd+Shift+R 强制刷新
4. 签到页点「刷新流量地址」
5. 仍不行：双击「光影盟-诊断」看报错

【只要局域网、不要隧道】
终端执行：GY_PUBLIC_TUNNEL=0 /Users/liwei/Photon/start.sh
