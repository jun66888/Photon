## 第 2 页 · 项目背景


### 第一章 项目概述与建设目标

#### 1.1 项目背景

随着互联网经济的深入发展，企业网站建设已从「有没有网站」升级为「网站能否带来营销转化」。传统建站方式周期长、成本高、维护难，难以满足中小企业快速上线、灵活运营的需求。自助建站频道作为中推网系统的核心模块之一，面向入驻商家及企业用户提供「模板选型 + 可视化编辑 + 多端同步 + 营销工具」的一站式建站解决方案。

参照演示站点 https://zgpptg.com/jianzhan/，本频道以「自助建站频道」为品牌定位，通过 PC 端展示建站产品能力、模板资源、设计服务及套餐标准，引导用户完成从认知、选型到下单的全链路转化。

#### 1.2 项目定位

| 维度 | 说明 |
|------|------|
| 产品名称 | 自助建站频道 |
| 访问域名 | `{主站域名}/jianzhan/`（演示：`https://zgpptg.com/jianzhan/`） |
| 目标用户 | 中小企业主、个体工商户、品牌方、区域门户运营者 |
| 核心价值 | 快速建站、多端覆盖、营销赋能、低成本运维 |
| 业务模式 | 模板建站 + 定制设计 + 建站商城 + 标准套餐 |

#### 1.3 建设目标

1. **展示目标：** 清晰呈现建站产品线（模板、设计、营销、商城、移动、定制、标准），提升品牌专业形象。
2. **转化目标：** 通过模板演示、案例展示、套餐对比，引导用户咨询或下单。
3. **体验目标：** PC 端 1200px 固定宽度布局，导航清晰，3 秒内完成首屏渲染。
4. **扩展目标：** 与中推网主站、会员系统、订单系统、分站系统无缝集成。

## 第 5 页 · 项目约束


#### 1.8 项目约束与假设

**技术约束**

1. 前台基于中推网 CMS 模板引擎，使用 `{# ... #}` 模板语法。
2. 静态资源路径：`/static/`（公共）、`/templates/website/skin1/`（频道模板）。
3. jQuery 1.8.3 + SuperSlide 2.1.1 作为基础 JS 依赖。
4. 页面字符编码 UTF-8，兼容 IE EDGE 及以上、Chrome、Firefox、Safari。

**业务约束**

1. 演示站点标注「非实际运营网站，所载信息仅供软件功能测试」。
2. 模板分类包括：节日、话题、人物、活动、事件等。
3. 建站套餐含域名、虚拟主机、企业邮箱等配套服务。

**假设条件**

1. 主站 `masterDomain` 已正确配置并可访问。
2. `channelDomain` 指向自助建站频道子目录。
3. 后台模块开关已启用，风格管理已选用 skin1 模板。

#### 1.9 成功标准

| 指标 | 目标值 |
|------|--------|
| 首页加载时间 | ≤ 3 秒（4G 网络） |
| 模板列表首屏展示 | ≥ 8 个模板卡片 |
| 导航切换 | 无整页刷新（同域跳转） |
| 演示链接 | 100% 可新窗口打开 |
| 移动端二维码 | 可扫描跳转主站 |
| SEO 三要素 | 每页独立 title/keywords/description |

## 第 9 页 · 搜索功能


#### 2.7 搜索功能规格

**入口位置：** Header 右侧  
**搜索范围：** 网站模板库（模板名称、分类）  
**请求方式：** GET  
**参数：** `keywords`（字符串，可为空）  

**前端交互**

1. 用户输入关键词，点击「搜索」或回车提交。
2. 跳转至 `templates.html?keywords={输入值}`。
3. 模板页根据关键词过滤列表（后台或前端过滤）。

**空值处理**

- 关键词为空时，展示全部模板列表。
- 无匹配结果时，显示「暂无相关模板」提示（建议实现）。

**SEO 影响**

- 搜索结果页 title 动态拼接：`"{关键词} - 模板搜索 - 自助建站"`。
- 使用 `rel="nofollow"` 避免无效搜索页被大量收录（可选策略）。

#### 2.8 频道与主站关系

| 关联点 | 说明 |
|--------|------|
| Logo 链接 | 返回主站首页 `{masterDomain}` |
| 移动版二维码 | 指向主站 URL，由 `qrcode.php?data={masterDomain}` 生成 |
| 微信公众号 | 后台配置图片 `{siteConfig.card}` |
| 帮助链接 | 统一跳转主站 help 系列页面 |
| 关于我们 | 主站 about-1 ~ about-4 页面 |
